# Sistema de Cadastro de Clientes

Aplicação web CRUD desenvolvida com PHP, MySQL, HTML, CSS e
JavaScript, com apoio de Inteligência Artificial no processo
de aprendizagem.

## Tecnologias

- PHP 8+ / PDO
- MySQL
- HTML5, CSS3, JavaScript

## Como executar localmente

1. Copie a pasta para o htdocs do XAMPP.
2. Importe o script SQL em config/database.sql via phpMyAdmin.
3. Acesse http://localhost/cadastro-clientes/
